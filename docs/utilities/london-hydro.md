# London Hydro (Ontario, Canada)

## Provider

London Hydro runs its own Green Button service, and also provides it for several other Ontario utilities.

## Information on File

Registration created by Raman Gupta (@rocketraman) using his own contact information.
See https://github.com/rocketraman/open-green-button/issues/9.

## Water Data

Not available.
London Hydro does not offer water usage through Green Button for any of the utilities it supports, including London Hydro itself, even where the utility bills you for water.
Water is supported by the Green Button standard but is not part of Ontario's Green Button mandate, so utilities are not required to implement it (confirmed by London Hydro, October 2026).
Only electricity data is available for London Hydro through Open Green Button.
See the [London Hydro provider notes](../providers/london-hydro.md).
